What it does

One proof bundle for your whole team

Record

Browser extension captures tab or desktop with clicks, inputs, navigation, console logs, and network requests — headers, cookies, bodies.

Review

Video player with timeline seek. Actions, logs, and network tabs. Detail drawer with raw data, copy cURL, copy response, merge actions.

Share

Org-scoped share links with expiry. Internal-only by default. Revoke anytime. Restricted screen prompts join org for external viewers.

Discuss

Cloud and share viewer comments. Session notes for local/ZIP viewers. Team discussion attached to each evidence record.

Debug

Network detail drawer with status, method, headers, body. Copy cURL for any request. AI token lets an LLM inspect the full session.

Prove

Export reviewed ZIP with merge annotations. Automation upload via API token. Source type automation-test for CI runs.
