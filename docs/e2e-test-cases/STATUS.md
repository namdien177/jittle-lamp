Evidence from production: ILHAM batch `01a10397-6622-…` (exploration `01a10397-69eb-…`) and PCF batch `01a10397-7868-…` (exploration `01a10397-7b16-…`). Their profiles ILHAM_ALL_ACCESS_ACCOUNT and PCF_ALL_ACCESS_ACCOUNT store a public `email` and a secret `password`, but the generated e2e config only read `JL_CRED_<P>_USERNAME`. The explorer therefore saw username "", tried guessed admin accounts (PCF), and stopped with AUTH_CREDENTIAL_UNAVAILABLE. e2e still reported `ended: finished`, and both items reached "Ready to commit": ILHAM with a single Assert claiming the login had failed (fallback after a 429 from alibaba/qwen3.7-flash, Retry after 14s), PCF with a lint error "No macro named Login". Fixes:
  - **Credentials.** Credentials now support an optional `loginField` role. Automatic uses an existing public `username`, otherwise the sole public field; ambiguous profiles require an explicit selection. `[Login]`, bare credential references and the engine use that role, while original fields remain available. Organisation public/secret declarations control prompt and compiler handling, including env overrides.
  - **Preflight.** Explorations fail before a browser starts when a profile the instructions name is missing (`missingProfiles` in the exploration config) or has no identifier or password.
  - **Outcome.** `explorationOutcome` passes only a run whose steps all passed, with no issue finding, that finished. Anything else keeps the instructions as Notes with the reason; the item is skipped by default, carries an explicit error, and the model is not asked.
  - **Grounding.** Backend lint knows the runner's built-in `Login` macro. The transcript prompt lists the allowed tags, macros and only the profiles the exploration was given. Model output with a parse or lint error, or an unknown profile, is rejected in favour of the explored steps.
  - **Rate limits.** A 429 with a Retry-After of 20 s or less is retried once; the runner allows 120 s for the result call.
  - **Runner pools link.** A heartbeat naming an exploration no longer becomes the worker's "Current run" (`/test-runs/<explorationId>` showed "Test run not found").

  Validation: 15 runner credential tests, 3 backend credential persistence/validation tests and 3 real Chromium credential tests.
